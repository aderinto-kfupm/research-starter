# MATLAB–Simulink Skill

You are helping a PhD researcher in Systems and Control build research-grade MATLAB analysis
and Simulink simulations. The context is UGV (Unmanned Ground Vehicle) soft computing —
fuzzy logic, neural networks, PSO/ACO optimization, and control system design.

Your outputs must be organized, well-documented, and publication-ready. A reviewer reading
the code should immediately understand the system being modeled, the parameters and their units,
and how to reproduce the results.

## Step 3: Write params.m First

The parameters file is always written first — everything else references it. Good parameter
organization prevents the most common source of bugs in research code (hardcoded magic numbers).

```matlab
% params.m — System parameters for <ProjectName>
% Units are annotated inline. Always pass 'p' as an argument to functions.

function p = params()
    % --- Physical parameters ---
    p.mass_kg        = 5.0;     % [kg]   Vehicle mass
    p.wheel_radius_m = 0.1;     % [m]    Wheel radius
    p.max_speed_mps  = 3.0;     % [m/s]  Maximum speed

    % --- Controller parameters ---
    p.Kp = 2.5;                 % [-]    Proportional gain
    p.Ki = 0.1;                 % [1/s]  Integral gain
    p.Kd = 0.05;                % [s]    Derivative gain

    % --- Simulation parameters ---
    p.t_end_s        = 10.0;    % [s]    Simulation end time
    p.dt_s           = 0.01;    % [s]    Time step
    p.solver         = 'ode45'; % [-]    ODE solver

    % --- Soft computing parameters (if applicable) ---
    % p.fis_file = 'fuzzy_controller.fis';
    % p.n_particles = 30;       % PSO swarm size
end
```

## Step 5: Build the Simulink Model Programmatically

Write `simulink/build_model.m` using the Simulink API. The script must:
1. Create (or recreate) the `.slx` model from scratch — never require manual editing
2. Position blocks to match the block diagram from Step 4
3. Set all parameters from the `params()` struct — no hardcoded values in the model

**Template for build_model.m:**
```matlab
function build_model(p, model_name)
% BUILD_MODEL  Programmatically constructs the Simulink model.
%   p          — parameter struct from params()
%   model_name — string name for the .slx file (without extension)
%
% Run this script whenever parameters change or the model needs to be rebuilt.
% The resulting .slx is saved in the simulink/ directory.

    %% --- Create or overwrite model ---
    if bdIsLoaded(model_name), close_system(model_name, 0); end
    if exist([model_name '.slx'], 'file'), delete([model_name '.slx']); end
    new_system(model_name);
    open_system(model_name);

    %% --- Add blocks (positions: [left top right bottom] in pixels) ---
    % Follow the layout from docs/block_diagram.png exactly.
    add_block('simulink/Sources/Step',           [model_name '/Reference'],   'Position', [50  100 80  130]);
    add_block('simulink/Math Operations/Sum',    [model_name '/Error'],       'Position', [150 100 180 130], 'Inputs', '+-');
    add_block('simulink/Continuous/PID Controller', [model_name '/PID'],      'Position', [250 90  320 140]);
    add_block('simulink/Continuous/Transfer Fcn', [model_name '/Plant'],      'Position', [380 90  460 140]);
    add_block('simulink/Sinks/Scope',            [model_name '/Scope'],       'Position', [550 100 580 130]);

    %% --- Configure block parameters ---
    set_param([model_name '/PID'], 'P', num2str(p.Kp), 'I', num2str(p.Ki), 'D', num2str(p.Kd));
    set_param([model_name '/Plant'], 'Numerator', '[1]', 'Denominator', '[p.mass_kg 1]');

    %% --- Connect blocks ---
    add_line(model_name, 'Reference/1',  'Error/1',   'autorouting', 'on');
    add_line(model_name, 'Error/1',      'PID/1',     'autorouting', 'on');
    add_line(model_name, 'PID/1',        'Plant/1',   'autorouting', 'on');
    add_line(model_name, 'Plant/1',      'Scope/1',   'autorouting', 'on');
    add_line(model_name, 'Plant/1',      'Error/2',   'autorouting', 'on'); % feedback

    %% --- Simulation settings ---
    set_param(model_name, 'StopTime',   num2str(p.t_end_s), ...
                          'FixedStep',  num2str(p.dt_s),     ...
                          'Solver',     'ode45');

    %% --- Save ---
    save_system(model_name, ['simulink/' model_name '.slx']);
    fprintf('Model saved: simulink/%s.slx\n', model_name);
end
```

See `references/simulink_api.md` for:
- The full library paths for all common blocks (Sources, Sinks, Math, Continuous, Discrete, etc.)
- Fuzzy Logic Toolbox and Neural Network Toolbox block paths
- Common `set_param` property names by block type

- Signal naming and bus routing

## Step 6: Write analysis.m and plot_results.m

**analysis.m** runs the simulation and computes metrics:
```matlab
function results = analyze(p, model_name)
    % Run simulation
    simOut = sim(model_name, 'StopTime', num2str(p.t_end_s));

    % Extract signals
    t  = simOut.tout;
    y  = simOut.yout{1}.Values.Data;

    % Compute standard control metrics
    results.t          = t;
    results.y          = y;
    results.rise_time  = compute_rise_time(t, y);
    results.overshoot  = (max(y) - y(end)) / y(end) * 100; % [%]
    results.settle_time = compute_settling_time(t, y, 0.02);
    results.sse        = abs(y(end) - 1.0);               % steady-state error

    % Save
    save('results/results.mat', 'results');
    writetable(struct2table(rmfield(results,{'t','y'})), 'results/metrics.csv');
end
```

**plot_results.m** produces publication-quality figures. See `references/matlab_style.md`
for the full plot formatting template (font sizes, line widths, export settings).

## Step 7: Write main.m

`main.m` is the single entry point that ties everything together:
```matlab
% main.m — Run the full <ProjectName> analysis pipeline
% Usage: run main.m from the project root directory

clear; clc; close all;
addpath(genpath('.'));  % Add all subfolders to path

%% 1. Load parameters
p = params();

%% 2. Build / rebuild Simulink model
build_model(p, '<model_name>');

%% 3. Run analysis
results = analyze(p, '<model_name>');

%% 4. Generate plots
plot_results(results, p);

fprintf('\nDone. Results in results/  |  Figures saved to plots/\n');
```

## Code Quality Standards

**Every file** gets a header:
```matlab
% <filename>.m
% <One-line description>
%
% Author   : [Researcher]
% Project  : UGV Soft Computing — KFUPM PhD Research
% Created  : <date>
% Modified : <date>
%
% Dependencies: params.m, [list others]
% Outputs     : [describe what this produces]
```

**Naming conventions:**
- Variables: `snake_case` with unit suffix where ambiguous (`vel_mps`, `angle_rad`, `time_s`)
- Parameters always in the `p` struct — never global variables
- Functions: `verb_noun` form (`compute_rise_time`, `build_model`, `plot_response`)
- Constants: `UPPER_CASE` (e.g., `G_MPS2 = 9.81`)

**No magic numbers** — every numeric value that isn't 0 or 1 lives in `params.m` with a comment.
