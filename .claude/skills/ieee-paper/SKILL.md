# IEEE Conference Paper Skill

You are helping a PhD researcher write and maintain a research paper in IEEE conference
format. The paper uses `IEEEtran` LaTeX class, follows IEEE conventions strictly, and
manages all references in `references.bib` compiled via BibTeX with the `IEEEtran`
bibliography style. **Never use `main.bbl` for manual reference management — always use
`references.bib` as the single source of truth for citations.**

The researcher works on UGV soft computing — fuzzy logic, neural networks, optimization
algorithms. Write with the voice and precision expected in IEEE Transactions / conference
proceedings.

---

## Step 1: Assess the Current State

Before writing anything:

1. **Check for `main.tex`** in the current working directory or project root.
   - If found: read it fully. Understand what sections exist, what's missing, what needs updating.
   - If not found: create it from the full template in `references/latex_templates.md § Main Template`.

2. **Check for `references.bib`**.
   - If found: read it — this is the canonical reference list. Never delete entries.
   - If not found: create it as an empty `.bib` file.
   - All citations are managed in `references.bib` and compiled via BibTeX (see Step 4).
   - Ignore any existing `main.bbl` file; it is auto-generated by BibTeX and must not be
     edited manually.

3. **Check for literature-review output**: look for `review/ver*.tex` files.
   - If found: read the latest version. Extract the `\thebibliography` section and thematic
     analysis sections. These feed directly into the Related Work section and reference list.
   - Tell the user what you found: "Found `review/ver2.tex` with 15 references — I'll use
     these for the Related Work section and bibliography."

4. Report your findings before writing: what exists, what will be created, what will be updated.

## Step 2: Confirm Paper Details (if `main.tex` is new)

If creating a new `main.tex`, confirm:
- **Title** (no symbols, no subtitles, no math — IEEE rule)
- **Authors** — name, department, institution, city/country, email or ORCID
- **Abstract** — no math, no symbols, no special characters (IEEE rule)
- **Index Terms** — 4–6 keywords, comma-separated, lowercase except proper nouns
- **Sections needed** — typical structure: Introduction, Related Work, Methodology/System
  Design, Results & Discussion, Conclusion, Acknowledgment
- **Conference/journal target** — informs tone and page limit

If the user says "just start writing," infer from context and state assumptions.

## Step 3: Write or Update Sections

Write each section following IEEE prose conventions (see `references/ieee_conventions.md`).

**Standard section order for a control/robotics paper:**
```
I.    INTRODUCTION
II.   RELATED WORK          ← fed from literature-review output if available
III.  SYSTEM MODEL / PROBLEM FORMULATION
IV.   PROPOSED METHOD / CONTROLLER DESIGN
V.    SIMULATION RESULTS
VI.   CONCLUSION
      ACKNOWLEDGMENT        ← unnumbered section*
      REFERENCES
```

When writing content:
- Every claim needs a citation: `\cite{key}` — never leave an uncited assertion
- Every equation gets a label: `\label{eq:name}` and is referenced via `\eqref{eq:name}`
- Every figure and table is cited in text before it appears
- Use `\IEEEPARstart{F}{irst}` for the first paragraph of the Introduction only

**Integrating from literature-review output:**
When `review/ver*.tex` exists, use its thematic sections to draft Related Work:
- Map each theme from the lit review to 1–2 paragraphs
- Preserve all citations, converting `\bibitem{key}` entries to the format in Step 4
- Focus on what the papers *don't* address — the gaps section from the review directly
  motivates the proposed method in Section III/IV
- Do not copy the lit review verbatim — synthesize and tighten for a 4–8 page paper

## Step 4: Manage References in references.bib

All references live in `references.bib`. The paper includes them via BibTeX in `main.tex`:
```latex
\bibliographystyle{IEEEtran}
\bibliography{references}
```

**Never use `\input{main.bbl}` or manually edit `main.bbl`** — `main.bbl` is auto-generated
by BibTeX and will be overwritten on each compile run.

**`references.bib` entry format (BibTeX):**
```bibtex
@article{key1,
  title     = {Title of paper with only first word and proper nouns capitalized},
  author    = {Author, A. and Author, B.},
  journal   = {IEEE Trans. Full Journal Name},
  volume    = {X},
  number    = {Y},
  pages     = {Z1--Z2},
  year      = {YYYY},
  publisher = {IEEE},
  doi       = {10.xxxx/xxxxx}
}

@inproceedings{key2,
  title     = {Conference paper title},
  author    = {Author, C. and Author, D. and Author, E.},
  booktitle = {Proc. Conf. Name Abbrev.},
  address   = {City, Country},
  year      = {YYYY},
  pages     = {Z1--Z2}
}

@mastersthesis{key3,
  title  = {Thesis title},
  author = {Author, F.},
  school = {University Name},
  year   = {YYYY}
}
```

**Citation key convention:** `firstauthorYYYY` — e.g., `ma2025`, `garg2022`, `hickling2026`

**When importing from literature-review output:**
1. Read the reference list from `review/ver*.pdf` or `review/ver*.tex`
2. Add each reference as a properly formatted BibTeX entry in `references.bib`
3. Never duplicate existing keys — check before adding
4. Report how many references were added: "Added 3 entries to `references.bib`."

**IEEE reference formats** — see `references/ieee_conventions.md § Reference Formats` for
journal, conference, book, thesis, arXiv, and website templates.

## Step 5: Final Quality Pass

Before finishing, check:

**Structure:**
- [ ] No template placeholder text remains (title, author, abstract, body)
- [ ] Abstract: no math, no symbols, no special characters
- [ ] Index Terms: 4–6 terms, lowercase, comma-separated
- [ ] `\IEEEPARstart{}{}` used for first paragraph of Introduction only
- [ ] Every section has at least one citation
- [ ] Acknowledgment section is unnumbered (`\section*{Acknowledgment}`)

**Equations:**
- [ ] All equations numbered and labeled
- [ ] All cross-references use `\eqref{}` not `(1)`
- [ ] `{align}` or `{IEEEeqnarray}` used — never `{eqnarray}`
- [ ] Symbols defined before or immediately after first use

**Figures & Tables:**
- [ ] All figures cited in text before they appear; captions below figures
- [ ] All tables cited in text before they appear; captions above tables
- [ ] Figure labels use 8pt Times New Roman (note in caption)
- [ ] `\label` placed *after* `\caption`, never before

**References:**
- [ ] Every `\cite{key}` in the text has a matching entry in `references.bib`
- [ ] No orphan bib entries (every entry is cited at least once)
- [ ] Paper titles: only first word and proper nouns capitalized
- [ ] All authors listed (IEEE requires all authors for ≤6; "et al." only for 7+)
- [ ] `\bibliographystyle{IEEEtran}` and `\bibliography{references}` used — never `\input{main.bbl}`
