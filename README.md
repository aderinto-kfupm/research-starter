## Quick start

`make` is not bundled with Git Bash on Windows: install it (`winget install ezwinports.make`) or run the commands from the `Makefile` directly.

```bash
make paper              # build writeup/main.pdf (needs latexmk + a TeX distribution)
make env                # Python: create .venv and install src/python + dev tools
make check              # fail on undefined citations/references (after make paper)
make test               # Python tests (pytest)
make matlab             # MATLAB: run src/matlab/run_all.m in batch mode
make matlab-test        # MATLAB: smoke test in tests/matlab
make init TOOL=python   # one-time: delete the unused toolchain, its tests and CI workflow (python|matlab)
make reproduce          # run the pipeline and regenerate every figure in figures/
```

Use one of the two toolchains per paper and delete the other (see [docs/environments.md](docs/environments.md)).

## Layout

| Path | Purpose |
|---|---|
| `writeup/` (`main.tex`, `references.bib`) | The paper (IEEEtran, BibTeX). `writeup/references.bib` is the single source of citations. |
| `figures/` | Figures included by `writeup/main.tex`. Generated by code, never edited by hand. |
| `src/python/`, `src/matlab/` | Analysis and simulation code. Pick one. |
| `data/raw/`, `data/processed/` | Inputs. Raw is read-only; large files stay out of git (see [data/README.md](data/README.md)). |
| `results/` | Generated numeric outputs (`.mat`, `.csv`). Gitignored. |
| `papers/` | PDFs of related work for `/literature-review`. Gitignored. |
| `review/` | Literature-review output (`ver1.tex`, `ver2.tex`, ...) from `/literature-review`. |
| `reviews/` | In-house peer-review reports from `/academic-paper-reviewer`. See [reviews/README.md](reviews/README.md). |
| `docs/` | Onboarding, methodology, reproducibility, the Claude workflow, paper plan, and submission checklist. |
| `.claude/skills/` | Project skills (writing, review, MATLAB). |
